# Rapid Review

Rapid Review is a modern web application and landing page designed for reputation management, helping businesses capture real 5-star reviews on Amazon and Google while filtering and handling negative feedback privately.

## Project Structure

```
.
├── assets/         # Static assets and media
├── css/
│   └── styles.css  # Application styles and design system
├── js/
│   └── main.js     # Client-side scripts and interactivity
├── index.html      # Main landing page
└── README.md
```

## Getting Started

Open `index.html` in any modern web browser or run with a local web server (e.g., Live Server, `npx serve`, or Python HTTP server).
